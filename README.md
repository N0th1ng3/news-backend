# Бэкенд-сервис для новостного Android-приложения

Прослойка (микросервис) между официальным сайтом Администрации Промышленновского округа и мобильным приложением. Собирает новости в режиме реального времени, кэширует в локальную базу данных и предоставляет REST API.

## Развернутое демо
* **API Список новостей**: [https://onrender.com](https://news-backend-90uu.onrender.com/news)
* **Интерактивная документация (Swagger)**: [https://onrender.com](https://news-backend-90uu.onrender.com/docs)

## Технологический стек
* **Язык**: Python 3.14
* **Фреймворк**: FastAPI (ASGI веб-сервер)
* **База данных**: SQLite3 (хранение и фильтрация)
* **Парсинг**: Requests + BeautifulSoup4

## Реализованные требования ТЗ
1. **Защита от дубликатов**: На уровне базы данных через ограничение `UNIQUE(source_url)`. Повторные новости отсекаются через перехват `sqlite3.IntegrityError`.
2. **Пагинация**: Поддержка параметров `limit` (ограничение количества) и `offset` (сдвиг выборки) для оптимизации трафика на мобильных устройствах.
3. **Отказоустойчивость**: Сетевой сборщик полностью изолирован блоками `try/except`. Если внешний сайт заблокирует запрос или упадет, сервер продолжит отдавать старые новости из базы и не упадет в `Internal Server Error`.

## Спецификация API
* `GET /news?limit=10&offset=0` — Возвращает список новостей с поддержкой постраничного вывода.
* `GET /news/{id}` — Возвращает детальную информацию о конкретной новости по её уникальному ID.
* `POST /refresh` — Запускает живой сборщик новостей с сайта `admprom.ru` для обновления базы данных.

## Локальный запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите сервер: `uvicorn main:app --reload`
